# E-Commerce_Sales_-_Customer_Analytics
Developed an interactive Power BI dashboard to analyze e-commerce sales performance, customer purchasing behaviour, product performance, and regional revenue trends.  The project uses a structured Star Schema data model consisting of one Fact Table and four Dimension Tables to provide meaningful business insights through data visualiza

Management wants a Power BI dashboard to understand:
•	Sales performance
•	Profitability
•	Customer behavior
•	Product performance
•	Regional performance
•	Monthly/quarterly trends
•	Delivery performance
Your job is to clean the data, create a data model, write DAX measures, and build an interactive dashboard.
